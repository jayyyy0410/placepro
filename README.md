# Placement Portal Application

A web application built with Flask, SQLite, and Bootstrap that allows
Admin, Companies, and Students to manage campus placement activities.
 
## Tech Stack
- Backend: Flask + SQLAlchemy
- Frontend: Jinja2 + Bootstrap 5
- Database: SQLite
 
## How to Run
1. pip install -r requirements.txt
2. python app.py
3. Open http://127.0.0.1:5000
